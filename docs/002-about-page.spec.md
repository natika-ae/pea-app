# Spec 002 — About Us Page

| รายการ | ค่า |
|---|---|
| สถานะ | Draft — ข้อความทั้งหมดในหน้าเป็นตัวอย่าง รอยืนยันจากศูนย์อบรม |
| ข้อจำกัด | ไม่ใช้ฐานข้อมูล เนื้อหาเก็บเป็นไฟล์ในโปรเจกต์ |

> เอกสารนี้บอกว่า **หน้านี้ต้องทำอะไรและเพราะอะไร** ไม่ระบุเทคโนโลยีหรือโครงสร้างโค้ด
> วิธีสร้างอยู่ใน plan และขั้นตอนลงมือทำอยู่ใน tasks

---

## 1. Goal

ผู้เยี่ยมชมเปิดหน้า `/about` แล้วรู้ภายใน 1 นาทีว่าศูนย์อบรมคือใคร ให้อะไรกับผู้เรียน มีผลงานเท่าไร และติดต่อได้อย่างไร จากนั้นไปหน้ารวมหลักสูตรต่อได้ทันที

## 2. Scope

**อยู่ในขอบเขต:** หน้า `/about` เนื้อหาคงที่ 5 ส่วน, ลิงก์ในเมนูหลัก, metadata สำหรับ SEO

**อยู่นอกขอบเขต:** ระบบแก้ไขเนื้อหาผ่านหน้า admin, ตัวเลขสถิติแบบ real-time จากฐานข้อมูล, แบบฟอร์มติดต่อ, แผนที่แบบฝัง, หลายภาษา

## 3. Page Content (top to bottom)

| ลำดับ | ส่วน | หัวข้อ | เนื้อหา |
|---|---|---|---|
| 1 | Hero | `h1` = ชื่อศูนย์ | คำอธิบาย 1 บรรทัด (ไม่เกิน 120 ตัวอักษร) และปุ่ม "ดูหลักสูตรทั้งหมด" ไป `/courses` |
| 2 | พันธกิจและวิสัยทัศน์ | `h2` "พันธกิจและวิสัยทัศน์" | วิสัยทัศน์ 1 ข้อ และพันธกิจ 1–5 ข้อเป็นรายการ |
| 3 | สิ่งที่ผู้เรียนได้รับ | `h2` "สิ่งที่ผู้เรียนได้รับ" | การ์ด 3 ใบพอดี แต่ละใบมีหัวข้อและคำอธิบายไม่เกิน 200 ตัวอักษร |
| 4 | ผลการดำเนินงาน | `h2` "ผลการดำเนินงาน" | ตัวเลข 4 ตัว: ปีที่ดำเนินงาน, จำนวนหลักสูตร, ผู้เรียน, ใบประกาศที่ออก พร้อมบรรทัด "ข้อมูล ณ {วันที่}" |
| 5 | ติดต่อเรา | `h2` "ติดต่อเรา" | ที่อยู่, โทรศัพท์ (กดโทรได้), อีเมล (กดส่งได้), เวลาทำการ |

## 4. Business Rules

| รหัส | กติกา |
|---|---|
| AB-01 | ตัวเลขแสดงแบบมีจุลภาคคั่นหลักพัน เช่น `12,500` |
| AB-02 | วันที่ "ข้อมูล ณ" แสดงแบบไทยปี พ.ศ. เช่น `30 กันยายน 2569` |
| AB-03 | ปีที่ดำเนินงาน = ปี พ.ศ. ปัจจุบันตามเวลาไทย − ปีก่อตั้ง (พ.ศ.) ไม่ต่ำกว่า 0 ไม่เก็บเป็นตัวเลขตายตัว |
| AB-04 | ตัวเลขอื่น (หลักสูตร ผู้เรียน ใบประกาศ) แก้ด้วยมือในไฟล์เนื้อหา และต้องแก้วันที่ "ข้อมูล ณ" ไปพร้อมกัน |
| AB-05 | เนื้อหาที่ผิดรูปแบบต้องทำให้ test ล้มก่อน deploy ไม่ใช่ไปแสดงผิดบนหน้าเว็บ |

## 5. Acceptance Scenarios

**AS-01 เปิดหน้าได้**
- When เปิด `/about`
- Then ได้ HTTP 200 และมี `h1` เพียงหนึ่งเดียวคือ "ศูนย์อบรมออนไลน์ การไฟฟ้าส่วนภูมิภาค"

**AS-02 ครบ 5 ส่วนตามลำดับ**
- Then หัวข้อ `h2` เรียงเป็น พันธกิจและวิสัยทัศน์ → สิ่งที่ผู้เรียนได้รับ → ผลการดำเนินงาน → ติดต่อเรา
- And ส่วนสิ่งที่ผู้เรียนได้รับมีการ์ด 3 ใบ

**AS-03 ไปหน้าหลักสูตร**
- When กดปุ่ม "ดูหลักสูตรทั้งหมด"
- Then ไปหน้า `/courses`

**AS-04 รูปแบบตัวเลขและวันที่** (AB-01, AB-02)

| ค่าในไฟล์เนื้อหา | แสดงบนหน้า |
|---|---|
| `learners: 12500` | `12,500` |
| `courses: 48` | `48` |
| `stats.asOf: "2026-09-30"` | `ข้อมูล ณ 30 กันยายน 2569` |

**AS-05 ปีที่ดำเนินงาน** (AB-03) ปีก่อตั้ง 2560

| เวลาปัจจุบัน | แสดง |
|---|---|
| `2026-10-27T10:00:00+07:00` | 9 ปี |
| `2026-12-31T23:59:59.999+07:00` | 9 ปี |
| `2027-01-01T00:00:00.000+07:00` (= `2026-12-31T17:00:00Z`) | 10 ปี |
| ปีก่อตั้ง 2569 กับวันที่ 27 ต.ค. 2569 | 0 ปี |

**AS-06 ติดต่อได้ในคลิกเดียว**
- Then เบอร์โทรเป็นลิงก์ `tel:021234567` และแสดงเป็น `02-123-4567`
- And อีเมลเป็นลิงก์ `mailto:training@example.com`

**AS-07 SEO**
- Then `<title>` คือ `เกี่ยวกับเรา | ศูนย์อบรมออนไลน์ กฟภ.`
- And `<meta name="description">` คือคำอธิบายใน Hero

**AS-08 เมนูหลัก**
- Given อยู่หน้าใดก็ได้
- Then เมนูหลักมีลิงก์ "เกี่ยวกับเรา" ไป `/about`
- And ลิงก์นี้มี `aria-current="page"` เฉพาะตอนอยู่หน้า `/about`

**AS-09 การเข้าถึง (Accessibility)**
- Then ตรวจด้วย axe แล้วไม่มี violation ระดับ `serious` หรือ `critical`

**AS-10 มือถือ**
- Given หน้าจอกว้าง 375 px
- Then ไม่มี scroll แนวนอน และการ์ด 3 ใบเรียงเป็นแนวตั้ง

**AS-11 เนื้อหาผิดรูปแบบถูกจับได้** (AB-05)

| ความผิดพลาดในไฟล์เนื้อหา | ผล |
|---|---|
| อีเมล `training@` | test ล้ม |
| เบอร์โทร `02-589-9000` (มีขีด) | test ล้ม — เก็บเป็นตัวเลขล้วน จัดรูปแบบตอนแสดง |
| ผู้เรียน `-1` | test ล้ม |
| ปีก่อตั้ง `2017` (เป็น ค.ศ.) | test ล้ม |
| การ์ด 2 ใบ | test ล้ม |
| วันที่ `30/09/2569` | test ล้ม |

## 6. Decisions

| ประเด็น | การตัดสินใจ | เหตุผล |
|---|---|---|
| ปีที่ดำเนินงานคำนวณตอนไหน | ตอนสร้างหน้า และสร้างใหม่ทุก 24 ชั่วโมง | หน้าเร็วเหมือน static และตัวเลขเปลี่ยนภายใน 1 วันหลังขึ้นปีใหม่ ยอมรับความคลาดเคลื่อนนี้ได้ |
| ทำไมไม่ดึงสถิติจากฐานข้อมูล | ใส่ด้วยมือพร้อมวันที่ | spec นี้ตั้งใจไม่ต่อฐานข้อมูล ตัวเลขผลงานใช้ประชาสัมพันธ์ ไม่ต้อง real-time |
| เบอร์โทรหลายเบอร์ | รองรับ 1 เบอร์ | ยังไม่มีความต้องการ |
